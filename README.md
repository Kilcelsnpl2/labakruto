# Лабораторная работа: Линейные

## Автор
Карпов Кирилл (Вариант 4)

## Цель
Определить КПД термодинамического цикла сжатия идеального газа

## Описание
Программа вычисляет КПД термодинамического цикла сжатия идеального газа по формулам 

## Исходные данные
- степень уменьшения объема a = 5,54
- степень сжатия газа b = 3,93
- показатель адиабаты y =1,45
- температур процесса T1=288 K 
	                  T2= 675 K

## Ожидаемые результаты
Программа выводит три значения периода:
- n1: из двух изобар и двух адиабат
- n2: из двух изохор и двух изотерм
- n3: из изотермы и адиабаты с изотермой
